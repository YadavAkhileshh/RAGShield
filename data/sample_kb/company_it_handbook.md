# Internal IT Support Handbook

## VPN Access

Employees working from outside the office must connect through the company VPN before accessing any internal systems. Download the VPN client from the internal Software Portal using your company credentials. After signing in, complete MFA verification and select the nearest server location. If the connection drops or fails to establish, check your internet connection first, restart the client, then try a different server. Never disable your firewall or endpoint protection to work around a VPN issue. If the problem persists, raise an IT ticket and include a screenshot of the error message.

## Password Policy

Passwords must be at least 14 characters. Use the self-service identity portal to reset your own password. After five failed login attempts the account is temporarily locked — contact the IT help desk if self-service recovery does not work. Never share your password or MFA code with anyone, including IT staff.

## Multi-Factor Authentication

MFA is required for email, VPN, cloud services, and other protected systems. Use the company authenticator app or a registered hardware key. SMS is only available as a backup recovery method when your primary method is unavailable.

## Software Installation

Install software only from the company Software Portal. Software not listed in the portal requires manager approval and an IT security review before installation. Admin access is not granted to bypass this process.

## Lost or Stolen Device

Report a lost or stolen company device to the IT help desk and your manager immediately. Include the device asset tag and last known location if you have them. IT will lock and wipe the device remotely. Do not try to recover the device yourself.

## Remote Work Setup

For home office setups, connect via VPN before accessing file shares or internal tools. Use company-issued devices where possible. Personal devices used for work must have the endpoint security agent installed and approved by IT.
