# IT Service Desk Runbook

## Email Issues

Start by checking whether the problem affects one user or multiple. Look at the service status dashboard before doing anything else. For a single user: sign out and back in, check mailbox quota, and test via the web client. If the issue affects a team or the whole company, escalate immediately rather than asking every user to troubleshoot individually.

## Slow or Unresponsive Laptop

Check CPU and memory usage, available storage, startup programs, pending OS updates, and endpoint security scan status. Do not disable security software as a troubleshooting step — this creates a security risk and rarely fixes performance issues. Escalate if hardware diagnostics report a failure or the device is shutting down unexpectedly after software-level steps have been completed.

## Software Access Requests

Route software access requests to the IT request portal. Requests need manager approval before IT processes them. Inform the user of the expected turnaround and check back in after the SLA window.

## Ticket Priority Guide

- P1: company-wide outage or active security incident — respond immediately
- P2: a team is blocked with no workaround — respond within 2 hours
- P3: a single user is blocked or experiencing degraded service — respond within 8 hours
- P4: general requests, low-impact issues, or information queries — respond within 2 business days

## New Employee Onboarding

Create the user account, assign software licences, provision the device from the approved hardware list, and walk the user through VPN setup and MFA enrollment on day one. Send the welcome email with IT portal access before the start date.

## Account Deprovisioning

When an employee leaves, disable the account on the last working day, revoke active sessions, remove software licences, and flag the device for collection. Complete the offboarding checklist within 24 hours of the termination date.
